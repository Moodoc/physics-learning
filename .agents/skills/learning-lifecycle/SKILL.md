# 学习全生命周期

让每一次正式学习服务于当前阶段目标，并用可追溯证据决定下一任务和阶段转场；不能用日期、文档状态或“教过”替代能力验证。

## 适用边界

以下任务使用本技能：

- 用户要求开始或继续正式学习；
- 创建、接续或批阅学习单；
- 选择唯一下一学习任务或更新 `state/current.md`；
- 判断阶段是否通过、创建阶段检查点或迁移焦点阶段。

以下任务不使用本技能：

- 一次性物理概念答疑；
- 只调整 Markdown 排版、链接或目录；
- 只执行 Git 检查、提交或推送操作。

## 开始或继续学习

1. 依次读取 `state/learner-profile.md`、`state/current.md`，再读取当前焦点阶段所在的路线文件。只在综合任务确实引用并行阶段时读取相应契约。
2. 运行 `scripts/check-lifecycle.ps1`。若路线、状态和证据互相矛盾，先修复一致性，不继续安排新内容。
3. 根据当前目标状态选择活动：
   - 诊断目标尚未取样：安排 `diagnostic`；
   - 所需知识尚未教学：先安排 `learning`，不要伪装成独立测验；
   - 已有引导证据但缺独立证据：换等价任务安排 `assessment`；
   - 需要延迟复核或真实迁移：安排新的表示方式、物理情境或项目任务。
4. 从 `templates/learning-session.md` 创建一份学习单，只设置一个主要 `stage_id`，并引用至少一个 `target_id`。没有指定时长时按约 90 分钟设计。
5. 学习者尚未作答时保持 `planned`；用户提交可验证结果后改为 `submitted`；完成逐目标批阅后改为 `reviewed`。

## 批阅与证据登记

- 按仓库的渐进提示规则批阅；代理自行计算只能用于核验，不能登记为学习者证据。
- 在 `AI 批阅` 的逐目标表记录实际帮助、证据状态、证据内容、订正闭环和复核债务。
- 使用了方法提示、框架或更强帮助时，最高登记为 `guided`。提示后订正必须换等价任务无提示完成，才能登记为 `independent`。
- 只改参数仍是熟悉类型练习，不登记为迁移。`robust` 必须有独立表现，并经过 7～14 天延迟复核或真正的新情境、新表示迁移；关键先修还应具备这两类证据，并在进入高依赖阶段前短抽样。
- 后续表现暴露遗忘时登记 `needs_refresh`，只重开具体目标，不抹除历史学习单。
- 已通过阶段的检查点保留为历史结论；出现 `needs_refresh` 后，允许只为该目标重开焦点、并行线或下一任务。后续 `learning`/`guided` 仍属于补强中，只有更晚日期重新达到当前契约最低证据才关闭债务。
- `reviewed` 只说明批阅工作流结束，不等于目标已验证或阶段已通过。

## 更新当前执行板

只在跨学习单状态发生变化时更新 `state/current.md`：

- 保留一个焦点阶段和零个或多个合法并行阶段；
- 逐目标链接证据并写清未满足项；
- 把关键能力的延迟复核放入队列；
- 只留下一个下一学习任务，且不得指向锁定阶段或已经满足退出要求的目标；仅在 `exit_review` 中，未见综合 `assessment` 可以重检已经达标的焦点目标；
- 不复制完成阶段清单或整张依赖图。完成状态由有效阶段检查点推导，可用性由路线依赖推导。

字段、表格和证据判定的完整契约见 [references/lifecycle-contract.md](references/lifecycle-contract.md)。创建或修改路线、状态、学习单、检查点时必须读该文件。

## 阶段退出与迁移

1. 所有退出目标达到契约规定的最低证据后，把 `focus_mode` 改为 `exit_review`。
2. 执行未见过的综合任务，语义审查答案正确性、独立程度、提示边界和迁移真实性。确定性脚本不替代这一步。
3. 通过时才创建 `checkpoints/stages/YYYY-MM-DD-<stage-id>.md`，逐目标链接已批阅证据，`decision` 只能是 `passed`。
4. 未通过时不创建失败或“有条件通过”检查点；将具体缺口和唯一下一任务写回当前执行板。
5. 检查点通过后才迁移焦点，并重新运行生命周期检查。依赖某个目标的下游阶段只在该目标证据满足时解锁，不要求错误地完成整个无关模块。

路线契约发生实质变化时同步递增 `contract_version`：目标集合或语义、最低证据、依赖、退出条件的改变都必须升级并重新审计；错字和不改变门槛的解释性澄清不升级。由于机器证据只精确到日期，上游依赖必须严格早于下游独立证据或检查点，同日只能作为引导预览。

## 确定性检查的边界

运行：

```powershell
pwsh -NoProfile -File .agents/skills/learning-lifecycle/scripts/check-lifecycle.ps1
```

脚本检查标识、引用、依赖图、状态、证据文件和检查点结构，并对解析失败采取失败关闭。它不判断物理答案是否正确、提示是否过多、任务是否构成真实迁移，也不决定教学安排是否最优；这些必须由本技能的语义审计完成。
