# 文档治理

让项目文档保持职责单一、按需加载、链接完整，并保留可追踪的学习证据结构。

## 判断所需操作

- 创建、拆分、移动或重组文档，或者需要判断长度和目录边界时，先完整读取[文档组织与长度规范](references/conventions.md)。
- 仅需验证现有 Markdown 时，可以直接运行检查脚本，不必加载完整参考规范。
- 内容正确性、物理推导、证据强度、迁移真实性、教学质量和阶段是否通过，由当前学习或调研任务及 `$learning-lifecycle` 负责；本技能只处理文档结构与可维护性。

## 执行流程

1. 检查当前工作区和相关入口，识别文档的受众、唯一职责、权威来源及更新周期。
2. 按参考规范决定保留、拆分、移动或建立索引；不要复制已有事实，也不要机械地按行数拆分。
3. 更新受影响的相对链接、入口和反向引用。学习单必须保留在同一文件中，长代码、数据和图像移入 `projects/`；路线契约、当前执行板、学习单和阶段通过检查点不得互相复制职责。
4. 运行：

   ```powershell
   pwsh -NoProfile -File .agents/skills/document-governance/scripts/check-docs.ps1
   ```

5. 逐项处理结果：`NOTICE` 用于提示超过建议目标，`WARN` 需要评估但不阻断，`ERROR` 必须修复；若错误来自任务范围外的现有改动，应明确报告而不是擅自修改。
6. 检查改动中没有重复规则、孤立文档、无关文件或意外生成物，再将结果交给当前任务后续流程。

## 操作边界

- 不因使用本技能获得额外的提交、推送、发布或删除授权；Git 检查点仍由 `$git-learning-checkpoint` 处理。
- 不把安全边界、学习证据规则和跨目录不变量仅放入子目录 `AGENTS.md`。
- 不为满足预算而删除学习者作答、AI 批阅或其他不可替代的学习证据。
- 新建或更新项目技能时，必须维护与技能一致的中文 `agents/openai.yaml`；普通文档任务不得无关修改技能元数据、示例文件或额外说明文档。
