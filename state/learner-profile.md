# 学习者档案

最后更新：2026-09-07。

本档案由 AI 根据学习者提供的信息和长期学习证据持续维护，供后续学习安排使用；学习者可以随时纠正，但无需另行维护。

## 当前基础

- 高中物理基础比较稳。
- 接触过微积分，理解最基础的微分和积分概念，但较高阶公式与原理已经生疏。
- 未系统学习线性代数，需要从基础开始。
- 熟悉 Python，但不熟悉它在物理研究中的常见建模、数值求解和验证方式。

以上内容主要来自学习者自述，不等同于已经通过学习证据验证的能力。

## 时间与目标

- 可长期投入：每周约 8 小时。
- 默认单次学习：约 90 分钟。
- 当前目标：系统入门，在约 18 个月内完成三个方向试学并选择主方向与辅助方向。
- 后续目标：选定方向后再进入 6～12 个月的论文拆解和简化复现训练。

## 协作偏好

- 项目内使用中文讲解，允许引用高质量英文一手课程和论文。
- 计算、推导和练习由学习者先完成，AI 负责安排、提示、核验和批阅。
- 错误反馈采用分级提示，不默认直接给完整解法。
- 讲清方法后，给出完整任务并留出自行组织推导的空间；不要默认把练习拆成只剩代入或拼接答案的小步。学习者于 2026-09-07 对过度逐步提示明确提出纠正。
- 学习记录应自然形成，避免为记录而记录。
- 学习者于 2026-09-07 选择每周轮换课程：每次约 90 分钟集中一个主题，一周内持续推进运动与微积分、线性代数与线性系统、Python 物理建模；不要求每次课都塞入所有课程。
- 基线完成后优先开展讲解与练习；独立评估用于检查已经教学的内容，不以反复评估替代正式学习。

## AI 教学判断

以下判断用于选择讲解起点和教学方式，可以随着后续证据修订；它们不替代 `state/current.md` 中的已验证成果和阶段性短板。

- 不需要从通用 Python 语法或完整高中力学重新开始；应把 NumPy、Matplotlib 和数值方法放进具体物理模型中学习。
- 当前的物理直觉和定性推理通常先于微分方程形式化与科学计算熟练度；适合采用“具体场景 → 数学表达 → 数值验证”的顺序。
- 批阅时应区分概念或建模问题与代入、化简、近似计算问题，避免由局部计算错误直接推断概念未掌握。

当前判断依据：[第一次基线诊断](../sessions/2026/08/2026-08-25-baseline-diagnostic.md)和[线性阻力学习单](../sessions/2026/08/2026-08-26-linear-drag-velocity.md)。
