# 基线诊断、运动与线性系统

建议时间：基线诊断 2 周，运动与变化 10 周，线性系统 12 周。

## 本模块原则

- 从运动、能量、振动等具体问题出发，在需要时学习微积分、线性代数和微分方程。
- 学习者熟悉 Python，因此不讲通用语法，直接使用数组、绘图、数值求解和误差检查。
- 微积分以恢复理解和物理应用为主；线性代数从基础系统学习，因为它是耦合振动、数值计算和量子力学的共同工具。
- 二能级系统只用于观察矩阵与物理状态的联系；未达到正式量子门槛前，不把预览记作量子能力。

## 基线诊断：2 周

诊断不是考试，也不据此直接标记“已掌握”。通过短题和解释任务确定真实起点：

- 代数、三角函数、指数与对数；
- 导数、定积分及其几何与物理意义；
- 向量分解、速度、加速度、功和能量；
- 使用 NumPy 生成数据、Matplotlib 绘图并解释坐标轴和单位；
- 从物理描述中识别变量、参数、初始条件和目标量；
- 阅读一小段英文题目或图注，识别少量物理术语并用中文复述含义。

英文部分只用于决定后续材料难度，不单独评级，也不作为物理能力证据。

诊断成果：一份已批阅学习单，以及写入 `state/current.md` 的具体补缺项。

## 运动与变化：10 周

围绕“如何从运动描述建立可验证模型”并行学习：

- 函数、极限、导数、链式法则和泰勒展开的直觉；
- 定积分、变量替换和微积分基本定理；
- 位置、速度、加速度及其图像和单位；
- 牛顿定律、受力图、约束和初始条件；
- 功、势能、动量、角动量和守恒定律；
- 密度与总量等局部量—累积量关系；
- 用解析结果、数值微分和数值积分相互校验，并检查步长误差和极限情况。

成果：完成一个运动建模任务，从位置或受力描述得到速度、加速度或能量，并用数值方法复核；能够用运动方程和能量方法分析同一简单系统，说明两种方法的适用范围。

## 线性系统：12 周

围绕“多个自由度如何共同运动”并行学习：

- 向量、内积、范数、正交与基；
- 矩阵、线性方程组和线性变换；
- 行列式的几何意义；
- 特征值、特征向量和对角化；
- 实对称矩阵、复向量与厄米矩阵的初步认识；
- 一阶、二阶常微分方程及其初始条件；
- 简谐、阻尼、受迫振动、共振、稳定性和时间尺度；
- 二自由度耦合振动、正常模式和相空间直觉；
- 使用 `numpy.linalg` 检查残差 `Av - λv`；
- 使用 `scipy.integrate.solve_ivp` 求解演化方程，比较解析解、数值解和步长误差。

量子概念预览：把二能级状态看作二维复向量，把可观测结构与厄米矩阵、特征值和特征向量建立直观联系。此处不正式引入测量公设或薛定谔动力学。

成果：

1. 分析一个二自由度耦合振动矩阵，解释特征值与正常模式的物理意义；
2. 建立并解释一个受迫阻尼振子的数值模型，包括方程、参数、单位、结果和局限。

## 过关条件

- 能解释导数和积分在至少两个物理场景中的意义；
- 能从受力与能量两种角度处理典型的一维力学问题；
- 能手算一个简单矩阵的特征值和特征向量，并用 Python 验证；
- 能把二阶运动方程改写为一阶方程组并进行数值求解；
- 能解释正常模式、初始条件、共振和至少一种数值误差来源；
- 能主动检查单位、数量级、初始条件和极限情况。

进入正式量子力学还需要完成[场与波](02-fields-waves.md)中的复数、波和边界条件门槛；通过本模块不等于已满足全部量子先修。
