# 场与波

建议时间：16 周。向量微积分与电磁场并行，复数和傅里叶工具与波、光学并行。

## 场与电磁学：8 周

围绕“空间中每一点的物理量如何产生作用并发生变化”学习：

- 偏导数、多变量函数、梯度、散度和旋度；
- 用简单向量场图像和计算解释这些工具的物理意义；
- 电荷、电场、电势和高斯定律；
- 电流、磁场、洛伦兹力和电磁感应；
- 麦克斯韦方程各项对应的物理关系；
- 电磁波、能流和边界条件的初步认识；
- 使用解析计算与 Python 场图相互验证。

向量微积分不是独立学完后再使用：每个算子都应与相应的场景配对。尚不能解释梯度、散度或旋度时，不进入依赖该工具的电磁场计算。

资源：[MIT 8.02 Electricity and Magnetism](https://ocw.mit.edu/courses/8-02-physics-ii-electricity-and-magnetism-spring-2019/)。按当前主题选取材料和习题，不要求完整跟完课程。

成果：绘制并解释简单电场，计算一个对称电荷分布，并说明变化的电场和磁场如何相互联系。

## 波与基础光学：8 周

围绕“局部扰动如何传播、叠加并形成可观测图样”学习：

- 复数和复指数在振动、相位与波中的表示；
- 波动方程、行波、驻波和边界条件；
- 正常模式、基础傅里叶分解、相速度和群速度；
- 反射、折射、偏振、干涉和衍射；
- 光学成像与衍射极限；
- 用解析尺度和 Python 图像相互校验。

量子概念预览：比较经典波的振幅、驻波和离散正常模式与量子波动语言的相似处，同时明确经典波强度不等同于量子概率。预览不替代正式的波函数与测量训练。

资源：[MIT 8.03 Vibrations and Waves](https://ocw.mit.edu/courses/8-03sc-physics-iii-vibrations-and-waves-fall-2016/pages/syllabus/)。该课程完整学习量很大，这里只选取与当前问题和能力门槛对应的材料。

成果：用解析式与 Python 图像比较单缝和双缝干涉/衍射，并解释参数改变的影响。

## 过关条件

- 能从向量场图像和简单计算解释梯度、散度和旋度；
- 能解释麦克斯韦方程各项对应的物理关系，并完成至少一个对称场计算；
- 能使用复数表示振动或行波，并解释相位；
- 能说明边界条件如何产生驻波或离散正常模式；
- 能解释基础傅里叶分解的用途；
- 能区分干涉与衍射，计算或模拟至少一种典型图样；
- 每个部分至少提交一组经过批阅的代表性计算或建模任务，错误已经订正。

满足本模块门槛，并同时满足[运动与线性系统](01-motion-linear-systems.md)中的特征值和微分方程门槛后，才能进入正式量子力学。
