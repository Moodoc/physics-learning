# 场与波

本文件定义两个各约 8 周的阶段。向量微积分在场阶段内教学，复数和傅里叶工具在波阶段内教学；这些工具只门控依赖它们的局部活动，不构成阶段对自身的依赖。

<a id="fields-electromagnetism"></a>
## 阶段：场与电磁学 {#fields-electromagnetism}

- stage_id: fields-electromagnetism
- contract_version: 1
- pace_hint: 8 周
- depends_on: motion-change

### 阶段目的

理解空间中的标量场和向量场如何描述相互作用，能够完成简单对称电磁场计算并解释时变电磁关系。

### 教学范围

围绕“空间中每一点的物理量如何产生作用并发生变化”学习：

- 偏导数、多变量函数、梯度、散度和旋度；
- 用简单向量场图像和计算解释这些工具的物理意义；
- 电荷、电场、电势和高斯定律；
- 电流、磁场、洛伦兹力和电磁感应；
- 麦克斯韦方程各项对应的物理关系；
- 电磁波、能流和边界条件的初步认识；
- 使用解析计算与 Python 场图相互验证。

向量微积分不是独立学完后再使用：每个算子都应与相应的场景配对。尚不能解释梯度、散度或旋度时，不进入依赖该工具的电磁场计算。

资源：[MIT 8.02 Electricity and Magnetism](https://ocw.mit.edu/courses/8-02-physics-ii-electricity-and-magnetism-spring-2019/)。按当前主题选取材料和习题，不要求完整跟完课程。

### 局部活动门槛

- 梯度、散度和旋度均在本阶段教学；尚不能解释某个算子时，只暂停依赖该算子的具体计算。
- `FE-02` 的高斯定律计算前先通过 `FE-01` 中散度和通量的局部短验；磁感应活动前短验旋度与环量。
- 第 4～6 周安排累计检索：面对未见的简单对称场，选择积分或微分表述，说明单位、对称性、边界和方法局限。

### 退出目标

| target_id | 类型 | 可观察表现 | 最低证据 | 代表性任务 |
|---|---|---|---|---|
| FE-01 | 关键先修 | 从图像和简单计算解释梯度、散度、旋度及各自单位 | robust | 对新向量场判断源、环流和标量场最陡方向 |
| FE-02 | 普通 | 使用电场、电势和高斯定律完成对称分布计算 | independent | 计算球对称或柱对称电荷分布的场 |
| FE-03 | 普通 | 解释洛伦兹力、电流磁场和电磁感应的关系 | independent | 分析带电粒子运动或变化磁通产生的电动势 |
| FE-04 | 普通 | 用物理语言解释麦克斯韦方程各项、能流和边界关系 | independent | 对给定电磁情境逐项说明来源和变化 |
| FE-05 | 关键先修 | 在新场景中选择合适表述并用解析计算与 Python 场图互验 | robust | 建模未见过的简化场分布并分析边界和局限 |

### 阶段成果

绘制并解释简单电场，计算一个对称电荷分布，并说明变化的电场和磁场如何相互联系。

### 退出条件与解锁

`FE-02` 至 `FE-04` 达到 `independent`，`FE-01`、`FE-05` 达到 `robust`，累计检索已批阅且订正闭环后通过。电磁学阶段是全路线必修，但不是 `quantum-foundations` 的阶段级先修。

<a id="waves-optics"></a>
## 阶段：波与光学 {#waves-optics}

- stage_id: waves-optics
- contract_version: 1
- pace_hint: 8 周
- depends_on: none

### 阶段目的

理解扰动如何传播、叠加并受边界约束，能够用复数、傅里叶直觉和数值图像解释基础波动与光学现象。

### 教学范围

围绕“局部扰动如何传播、叠加并形成可观测图样”学习：

- 复数和复指数在振动、相位与波中的表示；
- 波动方程、行波、驻波和边界条件；
- 正常模式、基础傅里叶分解、相速度和群速度；
- 反射、折射、偏振、干涉和衍射；
- 光学成像与衍射极限；
- 用解析尺度和 Python 图像相互校验。

量子概念预览：比较经典波的振幅、驻波和离散正常模式与量子波动语言的相似处，同时明确经典波强度不等同于量子概率。预览不替代正式的波函数与测量训练。

资源：[MIT 8.03 Vibrations and Waves](https://ocw.mit.edu/courses/8-03sc-physics-iii-vibrations-and-waves-fall-2016/pages/syllabus/)。该课程完整学习量很大，这里只选取与当前问题和能力门槛对应的材料。

### 局部活动门槛

- 复数与复指数在本阶段教学；依赖相量的活动先短验 `WO-01`，不要求入场前已经掌握。
- 涉及正常模式的活动先短验 `LS-04`、`LS-05`；缺失时只暂停该活动，不阻止复数、传播或基础光学教学。
- 傅里叶分解在本阶段教学；进入衍射频谱或群速度活动前先完成对应教学与引导练习。
- 第 4～6 周安排累计检索：在新的边界或表示方式下，从波动方程、相位和边界条件预测模式，再用数值图像复核。

### 退出目标

| target_id | 类型 | 可观察表现 | 最低证据 | 代表性任务 |
|---|---|---|---|---|
| WO-01 | 关键先修 | 使用复数和复指数表示振动或行波并解释振幅与相位 | robust | 在时域与复数表示之间转换一个新波形 |
| WO-02 | 关键先修 | 由波动方程和边界条件解释行波、驻波与离散模式 | robust | 对新的固定或周期边界求允许模式并验边界 |
| WO-03 | 普通 | 用基础傅里叶分解解释模式叠加、频谱或尺度 | independent | 分解简单周期信号并说明主要分量 |
| WO-04 | 普通 | 区分反射、折射、偏振、干涉与衍射并完成典型计算 | independent | 分析单缝或双缝图样及参数尺度 |
| WO-05 | 关键先修 | 在新光学情境中比较解析尺度与 Python 图像并解释误差和极限 | robust | 建模未见孔径或边界的传播/成像问题 |

### 阶段成果

用解析式与 Python 图像比较单缝和双缝干涉或衍射，标明参数与单位，并解释改变参数的影响和模型局限。

### 退出条件与解锁

`WO-03`、`WO-04` 达到 `independent`，`WO-01`、`WO-02`、`WO-05` 达到 `robust`，累计检索已批阅且订正闭环后通过。`quantum-foundations` 只读取 `WO-01`、`WO-02` 与[线性系统](01-motion-linear-systems.md#linear-systems)的 `LS-02`、`LS-03`；不要求先通过整个 `fields-electromagnetism`。
