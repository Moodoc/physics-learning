# 基线诊断、数学与物理建模

建议时间：基线诊断 2 周，正式学习 16 周。

## 本阶段原则

- 学习者熟悉 Python，因此不讲通用语法，直接进入数组、绘图、数值求解和误差检查。
- 微积分以恢复理解和物理应用为主，不以背诵高阶公式为目标。
- 线性代数从零系统学习，因为它是后续量子力学、耦合振动和数值计算的共同工具。

## 基线诊断：2 周

诊断不是考试，也不据此标记“已掌握”。通过短题和解释任务确定真实起点：

- 代数、三角函数、指数与对数；
- 导数、定积分及其几何与物理意义；
- 向量分解、速度、加速度、功和能量；
- 使用 NumPy 生成数据、Matplotlib 绘图并解释坐标轴和单位；
- 从一个物理描述中识别变量、参数、初始条件和目标量。

诊断成果：一份已批阅学习单，以及写入 `state/current.md` 的具体补缺项。

## 微积分复习：4 周

- 函数、极限、导数、链式法则和泰勒展开的直觉；
- 定积分、变量替换和微积分基本定理；
- 位置—速度—加速度、功—势能、密度—总量等物理联系；
- 用解析结果和数值积分相互校验。

成果：完成一个“从位置函数得到速度和加速度，并用数值方法复核”的小任务。

## 线性代数：6 周

- 向量、内积、范数、正交与基；
- 矩阵、线性方程组和线性变换；
- 行列式的几何意义；
- 特征值、特征向量和对角化；
- 实对称矩阵、复向量与厄米矩阵的初步认识；
- 使用 `numpy.linalg` 计算，并检查残差 `Av - λv`。

成果：分析一个二自由度耦合振动矩阵，解释特征值与正常模式的物理意义。

## 微分方程与向量微积分：6 周

- 一阶、二阶常微分方程；
- 简谐、阻尼和受迫振动；
- 初始条件、稳定性和时间尺度；
- 偏导数、多变量函数、梯度、散度和旋度；
- 用 `scipy.integrate.solve_ivp` 求解简单演化方程；
- 比较解析解、数值解、步长误差和极限情况。

成果：建立并解释一个受迫阻尼振子的数值模型，包括方程、参数、单位、结果和局限。

## 过关条件

- 能解释导数和积分在至少两个物理场景中的意义；
- 能手算一个简单矩阵的特征值和特征向量，并用 Python 验证；
- 能把二阶运动方程改写为一阶方程组并进行数值求解；
- 能从向量场图像解释梯度、散度或旋度中的至少两个；
- 能主动检查单位、初始条件、数值误差和极限情况。
